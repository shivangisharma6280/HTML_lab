# Single-Page CV

A simple, single-page CV built using **HTML5** and minimal **CSS**. This project focuses on semantic HTML structure, basic styling, and organizing resume information.

## Features

- Semantic HTML5 structure
- Sections for Education, Skills, and Career History
- SEO-friendly meta tags
- Open Graph (OG) tags for social media sharing
- Custom favicon
- Clean and organized HTML code
- Applying basic CSS styling

## Technologies Used

- **HTML5**
- **CSS** (Minimal Styling)

## Project Structure

```text
single-page-cv/
├── index.html
└── README.md
```

## How to Run

1. Clone or download the repository.
2. Open the `index.html` file in any web browser.
